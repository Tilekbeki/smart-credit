# Smart Credit — backend

Backend MVP: заявки, синтетические профили компаний, статусы, имитация ФНС и БКИ, взаимодействие со scoring-сервисом.

В документе продукта бизнес-правила кредитного решения ещё не утверждены. Поэтому этот стартовый репозиторий не принимает кредитных решений; код содержит только health endpoint и общий словарь статусов. Реальные решения добавляются после согласования правил и API.

## Запуск

```sh
python3 -m backend.app
```

Проверка: `http://localhost:8000/health`.

## Границы

- Frontend вызывает backend через `/api/v1`.
- Backend вызывает scoring через `POST /v1/score`; версия контракта находится в `contracts/scoring.schema.json`.
- Проверки ФНС/БКИ для MVP должны использовать только локальные синтетические данные.
- Изменение контракта требует согласованного обновления backend и scoring, затем frontend при изменении публичного API.

CI этого репозитория запускается только для его изменений.
