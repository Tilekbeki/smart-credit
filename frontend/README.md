# Smart Credit — frontend

Веб-интерфейс MVP «Умный кредитный кабинет предпринимателя».

Этот репозиторий отвечает за страницы предпринимателя и сотрудника банка, формы и отображение статуса заявки. Источник данных и правила принятия решения находятся в backend; расчёт скоринга — в отдельном scoring-сервисе.

## Запуск

Откройте `index.html` в браузере. Пока это стартовая страница для команды, без подключения к API.

## Контракт и CI

Клиент обращается к backend по `/api/v1`; описание API хранится в backend-репозитории. CI этого репозитория запускается только для его изменений.

Не добавляйте реальные персональные или банковские данные в исходники и тестовые фикстуры.
