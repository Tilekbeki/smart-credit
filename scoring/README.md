# Smart Credit — scoring

Отдельный сервис объяснимого кредитного скоринга для MVP. Команда Data Science / ML ведёт его независимо от frontend и backend.

Пока модель, пороги и бизнес-правила не согласованы, этот стартовый репозиторий не рассчитывает балл и не выдаёт кредитное решение. Он возвращает явный статус `not_implemented`, чтобы заглушка не выглядела как реальная оценка клиента.

## Запуск

```sh
python3 -m scoring.app
```

Проверка: `http://localhost:8001/health`. Контракт запроса `POST /v1/score` описан в `contracts/scoring.schema.json`; при подключении backend следует зафиксировать также контракт ответа и версионировать изменения в обоих репозиториях.

Используйте только синтетические тестовые данные. CI этого репозитория запускается только для его изменений.
